# Registro de avances

Cada archivo de esta carpeta resume una tarea terminada. Sirve para que las personas del equipo y sus asistentes de IA sepan qué se hizo, qué se decidió y qué falta, sin tener que leer todo el código.

## Reglas

- Un archivo por tarea terminada, creado en el mismo PR del código.
- Nombre: `AAAA-MM-DD-usuario-tema.md`, por ejemplo `2026-12-05-Derling07-pantalla-perfil.md`.
- Máximo 25 líneas. Corto y concreto.
- Nunca se edita ni se borra la entrada de otra persona. Si algo cambió, se crea una entrada nueva.
- Nunca claves, contraseñas ni datos personales de participantes.
- Antes de empezar una tarea, leer las 10 entradas más recientes.
